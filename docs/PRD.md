## 1. 产品概述

### 1.1 一句话定义
**AI 原生的一人内容工作室**——让个人创作者用 AI 完成「选题→创作→改写→出图→分发」全链路，一人运营多平台多账号。

### 1.2 要解决的核心问题
| 痛点 | 现状 | ContentPilot 解法 |
|------|------|-------------------|
| 一人多号，内容重复搬砖 | 同一篇笔记手动改格式发3-4个平台 | AI 一键改写+适配各平台格式 |
| 选题靠灵感，不稳定 | 拍脑袋选题，爆款率低 | 数据驱动选题推荐 |
| 创作耗时长 | 写稿+找图+排版占80%时间 | AI 写稿+AI 出图+自动排版 |
| 风格不统一 | 不同平台人设割裂 | 统一人设模板+风格控制 |
| 发布靠手动 | 定时发布靠闹钟 | 排期日历+一键分发 |

### 1.3 不是什么
- **不是** Postiz 那样的海外社媒排期工具（我们聚焦中文生态+AI内容创作）
- **不是** CMS 或笔记软件（我们不做内容编辑器，AI生成后微调即可）
- **不是** 团队协作工具（面向个人创作者的一人工作室）

## 2. 目标用户

### 2.1 核心用户画像
| 维度 | 描述 |
|------|------|
| 身份 | 一人多号的个人创作者 / 小团队(1-3人) |
| 平台 | 小红书 + 公众号 + 抖音 + B站（中文生态四大平台） |
| 赛道 | 养生/知识IP/金融/职场等垂直领域 |
| 痛点强度 | 已经在2+平台运营，深受「搬砖式运营」折磨 |
| 付费意愿 | 愿意为省时间付费（月省10+小时 = 值） |

### 2.2 典型场景

**场景A：小红书博主扩平台**
> 小红书3万粉的养生博主，想同步做公众号+抖音，但一个人根本忙不过来。用 ContentPilot：小红书笔记 → AI改写公众号长文 → AI提炼抖音脚本 → 一键分发。

**场景B：一人多号矩阵**
> 炒股博主同时运营3个号（价值投资号/科技股号/ETF号），每天要出9篇内容。用 ContentPilot：选题推荐 → 批量生成 → 各号风格微调 → 排期发布。

**场景C：从0起号**
> 新人想做小红书+公众号，不知道发什么。用 ContentPilot：赛道分析 → 选题日历 → AI生成+出图 → 发布+数据回收。

## 3. 功能需求

### 3.1 功能架构总览

```
ContentPilot
├── F1 选题中心 — 数据驱动的选题发现与规划
├── F2 创作工坊 — AI驱动的全链路内容生产
├── F3 风格引擎 — 统一人设与平台适配
├── F4 分发枢纽 — 多平台一键发布与排期
├── F5 数据看板 — 内容表现追踪与复盘
└── F6 系统设置 — 账号管理/模板配置/偏好
```

---

### F1 选题中心

| ID | 功能 | 优先级 | 描述 |
|----|------|--------|------|
| F1.1 | 热点追踪 | P0 | 接入热搜，按赛道过滤，推荐可蹭热点 |
| F1.2 | 爆款雷达 | P0 | 输入赛道关键词，搜索近7天爆款内容，提取流量密码 |
| F1.3 | 选题日历 | P1 | 可视化日历视图，拖拽排期，支持按平台/账号筛选 |
| F1.4 | 选题评分 | P1 | AI 评估选题热度×竞争度×匹配度，给出推荐指数 |
| F1.5 | 竞品监控 | P2 | 关注竞品账号，自动追踪其发布动态与爆款规律 |

---

### F2 创作工坊

| ID | 功能 | 优先级 | 描述 |
|----|------|--------|------|
| F2.1 | AI 写稿 | P0 | 根据选题+人设模板，生成各平台风格文案 |
| F2.2 | AI 出图 | P0 | 根据文案自动生成封面图+内容卡片 |
| F2.3 | 一键改写 | P0 | 一篇源内容 → AI改写为多平台版本 |
| F2.4 | 模板库 | P1 | 保存各平台内容模板，新内容自动套用 |
| F2.5 | 素材库 | P1 | 管理常用素材，创作时AI自动引用 |
| F2.6 | 人工微调 | P0 | AI 生成后支持人工编辑修改 |

---

### F3 风格引擎

| ID | 功能 | 优先级 | 描述 |
|----|------|--------|------|
| F3.1 | 人设档案 | P0 | 定义每个账号的人设，AI生成时严格遵守 |
| F3.2 | 风格学习 | P1 | 上传历史爆款内容，AI学习写作风格 |
| F3.3 | 平台适配 | P0 | 同一内容不同平台自动调整风格格式 |
| F3.4 | 合规检查 | P1 | 自动检测违禁词/敏感词 |

---

### F4 分发枢纽

| ID | 功能 | 优先级 | 描述 |
|----|------|--------|------|
| F4.1 | 多平台发布 | P0 | 支持一键发布（API或RPA） |
| F4.2 | 排期发布 | P0 | 设置发布时间，定时自动发布 |
| F4.3 | 发布预览 | P0 | 发布前预览各平台最终效果 |
| F4.4 | 发布状态 | P1 | 追踪每条内容的发布状态 |
| F4.5 | 回收站 | P2 | 发布失败的内容可一键重试 |

| B站 | 创作中心API | P2 |

## 4. MVP 定义（v0.1）

**核心闭环**：选题 → AI生成 → 一键改写多平台 → 出图 → 导出/发布

| 模块 | MVP 包含 | MVP 不包含 |
|------|----------|------------|
| F1 选题中心 | ✅ 热点追踪<br>✅ 爆款雷达 | ❌ 选题日历/评分/竞品监控 |
| F2 创作工坊 | ✅ AI写稿<br>✅ AI出图<br>✅ 一键改写<br>✅ 人工微调 | ❌ 模板库/素材库 |
| F3 风格引擎 | ✅ 人设档案<br>✅ 平台适配 | ❌ 风格学习/合规检查 |
| F4 分发枢纽 | ✅ 公众号推草稿箱<br>✅ 其他平台导出 | ❌ 直发/排期/状态追踪 |
| F5 数据看板 | ❌ 全部 | 全部 |
| F6 系统设置 | ✅ 人设配置<br>✅ 公众号绑定 | ❌ 其他平台/模板管理 |

### MVP 验收标准

1. 输入选题关键词，10秒内返回4平台文案
2. 一键生成小红书3:4封面图+公众号2.35:1封面图
3. 输入源内容，AI改写后4个版本差异>30%
4. 公众号草稿箱推送成功（含排版+封面）
5. 其他平台内容导出为标准格式文件

## 5. 技术方案

| 层 | 技术 | 理由 |
|----|------|------|
| 前端 | Next.js 15 + TypeScript + Tailwind CSS 4 | GitHub高星标配，SSR+API一体化 |
| UI组件 | shadcn/ui | 可定制，社区活跃 |
| 图表 | ECharts | 中文生态好 |
| 后端 | Next.js API Routes | 全栈统一 |
| AI | OpenAI API / DeepSeek API | 文案生成+改写+风格适配 |
| 图片生成 | 火山引擎/Replicate API | 封面图+内容卡片 |
| 数据库 | SQLite (Prisma ORM) | MVP轻量 |
| 部署 | Vercel | Next.js原生支持 |
| 公众号 | 已有腾讯云代理 | 推草稿箱API已验证 |

## 6. 竞品对比与差异化

| 维度 | Postiz | TryPost | ContentPilot |
|------|--------|---------|-------------|
| 定位 | 社媒排期工具 | AI社媒排期 | AI内容创作+分发 |
| 核心能力 | 排期+发布 | 排期+AI文案 | AI选题+创作+改写+出图+分发 |
| 目标市场 | 海外 | 海外 | 中文生态 |
| AI深度 | 浅 | 中 | 深(全链路AI) |
| 目标用户 | SaaS团队 | 小团队 | 个人创作者 |

**差异化四点**：①中文生态原生 ②AI原生不是排期优先 ③面向个人创作者 ④垂直赛道模板
